# Security policy

This project is unreleased. No supported production release exists yet.

Do not post vulnerabilities, credentials, private metrics or sensitive diagnostic
output in public issues. No private reporting channel is available yet because
repository ownership and hosting are pending. A confidential reporting contact or
repository security advisory channel must be configured before a public release.

When that channel is available, include affected versions, reproduction steps,
impact and a minimal example with sensitive data removed.
